# Titan frontend

Svelte 5, TypeScript, Tailwind CSS, and Vite UI for the Titan Wails desktop app.

See the [project README](../README.md) for prerequisites and full application setup.
From this directory run `npm ci`, `npm run check`, `npm test`, and `npm run build`.
Tests require Node.js 24. Desktop APIs in `wailsjs` are generated by Wails and must
not be edited manually. A frontend-only browser session has no native SVN API.
